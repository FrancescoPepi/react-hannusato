# Help Images

This folder contains explanatory images for the app's help section.

Images should be named according to the feature they illustrate, for example:
- search.png - Shows the search functionality
- filters.png - Shows the filter options
- recent_searches.png - Shows the recent searches feature
- product_card.png - Shows the product card layout
- navigation.png - Shows the navigation features
- platforms.png - Shows the supported platforms
